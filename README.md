# «Эхо Забытых Стен» — психологический хоррор на Bevy

Хоррор от первого лица на движке **Bevy 0.16** (Rust, ECS).
Герой с фонариком блуждает по тёмному процедурному лабиринту и собирает
5 фрагментов эха. Бег расходует стамину, а бег **на пустой стамине**
сводит с ума — и тогда приходят скримеры.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | движение |
| мышь | обзор |
| `Shift` | бег (тратит стамину) |
| `Esc` | выход в меню |
| `Enter` / `Space` / клик | старт из меню |
| `R` | рестарт после победы или смерти |

⚠️ **Бег на пустой стамине = принудительный бег = рост безумия.**
На экране нет никаких подсказок и счётчиков - только маленькая тусклая
полоска стамины снизу и красная виньетка безумия по краям экрана.
Рекомендуются наушники.

## Запуск

Нужен Rust (stable, 1.84+): https://rustup.rs

```bash
cargo run --release
```

Первый запуск скачает зависимости Bevy и может собираться 5–15 минут —
это нормально. Дальнейшие сборки быстрые.

> Запускайте именно через `cargo run` из корня проекта: игра ищет папку
> `assets/` относительно рабочей директории.

Системные зависимости для сборки Bevy под Linux (Debian/Ubuntu):

```bash
sudo apt install pkg-config libasound2-dev libudev-dev libxkbcommon-x11-0
```

Все звуки и картинки в `assets/` — процедурные заглушки, сгенерированные
для проекта. Их можно (и нужно!) заменить своими.

## Свои ассеты: как заменить

Просто положите свои файлы **с теми же именами** в те же папки:

- `assets/screamers/skrimer1.png` … `skrimer3.png` (PNG, желательно 16:9);
- `assets/audio/scream1.mp3` … `scream3.mp3` (короткие, ~1 секунда);
- `assets/audio/menu.mp3`, `assets/audio/ambient1.mp3`, `assets/audio/ambient2.mp3`.

Пары связаны индексом: сработавший скример №2 покажет `skrimer2.png`
и проиграет `scream2.mp3`.

Всего пар: 6, дважды подряд одна и та же не выпадает (антиповтор).

Стены/пол/потолок берут PNG из `assets/textures/` (заброшка); если файлов
нет - автоматически используются процедурные текстуры из `src/textures.rs`.

**Важно:** все файлы опциональны. Если каких-то нет:

- игра не падает и не спамит ошибками — скример без PNG мигает
  красно-чёрной заглушкой, отсутствующий звук просто пропускается;
- наличие файлов проверяется заново при каждом срабатывании, а музыка —
  каждые 5 секунд, поэтому файлы, положенные в `assets/` **при запущенной
  игре**, подхватятся автоматически, без перезапуска.

## Как устроены ключевые механики

**Стамина и принудительный бег** (`src/player.rs`, `stamina_system`):
максимум 100, бег тратит 16/с. Если стамина 0, но игрок продолжает держать
`Shift` и двигаться — поднимается флаг `ForcedRun`, скорость бега
сохраняется, но безумие растёт.

**Безумие и скримеры** (`src/hallucinations.rs`):
скрытый параметр 0–100 (+14/с в принудительном беге, −8/с на отдыхе).
Триггер — порог 100 **или** случайный таймер 5–10 с. Срабатывание:
случайная пара `skrimerN.png` + `screamN.mp3`, картинка — UI-нода на весь
экран поверх всего, звук — на максимальной громкости, управление
заблокировано. Таймер `Timer::from_seconds(1.0, TimerMode::Once)` ровно
через секунду удаляет картинку (`despawn`), безумие сбрасывается в 0.

**Звук** (`src/audio.rs`): в меню — зацикленный `menu.mp3`, в игре —
`ambient1/ambient2` по очереди с плавным нарастанием каждого трека;
переключение бесшовное, по факту окончания (`AudioSink::empty`), поэтому
подстраивается под любую длительность файлов. Смена состояний — через
плавные затухания, без обрывов.

**Тень** (`src/shadow.rs`): половина срабатываний скримера - 3D-режим: вместо картинки прямо перед игроком (2-3 м, с проверкой стен) появляется чёрная тварь ~2.5 м со светящимися глазами и за 0.6 с бросается в лицо. Звук и блокировка - те же.

**Смерть** (`src/player.rs` + `src/main.rs`): в момент истощения стамины - бросок 25% на смерть. Экран "YOU DIED", рестарт по R (победа и смерть взаимоисключающие).

**Лампы и тьма** (`src/atmosphere.rs`): потолочные светильники через каждые 3 клетки - рабочие (тёплые, с гало и пылью в свете), мигающие-неисправные (~30%) и разбитые (~15%, висят криво, без света). Каждый забег выбираются 2 тёмные зоны, где ламп нет вообще. Спавн игрока всегда освещён.

**Мир** (`src/main.rs`): каждый забег — новый случайный лабиринт 21×15
(backtracker + «заплетение» тупиков в петли), процедурные текстуры бетона/плитки/панелей, 5 светящихся фрагментов
в дальних клетках, AABB-коллизии, спотлайт-фонарик с мерцанием от безумия, экспоненциальный туман, виньетка и зерно плёнки.

## Настройка баланса

Все «крутилки» — константы в начале файлов:

- `src/player.rs`: `WALK_SPEED`, `RUN_SPEED`, `Stamina::{DRAIN,REGEN}_*`;
- `src/hallucinations.rs`: `INSANITY_THRESHOLD`, `INSANITY_GAIN_PER_SEC`,
  `RANDOM_TRIGGER_*`, `TRIGGER_COOLDOWN_SECS`, `SCREAMER_DURATION_SECS`;
- `src/audio.rs`: `MENU_VOLUME`, `AMBIENT_VOLUME`, `FADE_*_SECS`;
- `src/main.rs`: `MAZE_W/H`, `FRAGMENT_COUNT`, `CELL`, `WALL_H`;
- `src/textures.rs`: разрешение текстур и плотность шума/пятен;
- `src/shadow.rs`: дистанции появления/выпада тени (`SHADOW_*`).
- `src/atmosphere.rs`: яркость и шаг ламп (`LAMP_*`), шансы мигания/поломок, тёмные зоны, плотность тумана (`FOG_DENSITY`).
